# Support

## Asking questions

- **Usage questions and ideas:** open a GitHub issue; questions are welcome
  there.
- **Bugs and feature requests:** open a GitHub issue using the templates.
- **Security vulnerabilities:** never in public -- see [`SECURITY.md`](SECURITY.md).
- **Conduct concerns:** see [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).

Before asking, check the [README](README.md), [`deploy/README.md`](deploy/README.md)
and [`docs/`](docs/).

## What is not supported

Vulngraph is a community, best-effort open-source project.

- There is **no SLA**: no guaranteed response or fix times.
- No private or paid support, and no support for modified forks.
- Only `main` and the latest release are supported (see `SECURITY.md`).
- Help with your own cloud/IAM environment, custom deployments, or
  third-party integrations is out of scope beyond what is documented.
